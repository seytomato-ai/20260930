# 미마감 정리 도우미

나이스 출결 화면의 **미마감** 칸을 캡처해서 넣으면, 학생 시간표에서 과목·담당 교사를 찾아
미마감 요청 엑셀(`학번/학급 | 이름 | 날짜 | 과목 | 교시 | 출결 종류 | 담당 교사 | 요청중/완료 | 전달 사항`)로 정리해 주는 웹앱입니다.

## 사용 순서
1. **학생 시간표**를 넣습니다. 여러 파일(여러 주차)을 한 번에 넣어도 됩니다.
   - **나이스 학생별 시간표 PDF** 그대로 (한 쪽에 학생 한 명, 회전된 표도 인식, 해당 주 날짜로 조회). 등록되지 않은 주차는 다른 주에서 추정하지 않습니다.
   - 또는 엑셀 (양식은 화면의 “시간표 양식 내려받기”). 파일 목록에서 각 파일의 주 시작일(월요일)을 지정합니다. 파일은 추가로 불러오거나 목록에서 뺄 수 있습니다.
   - 가로형: `번호 | 이름 | 월1 … 금7`, 칸에는 `과목(교사)`
   - 세로형: `번호 | 이름 | 요일 | 교시 | 과목 | 교사`
   - 이름이 `공통`인 줄은 반 전체 기본 시간표, `과목-교사` 시트가 있으면 교사 이름을 채워 줌
2. **동아리 명단 PDF 또는 엑셀**을 넣습니다. 열은 `번호 | 성명 | 부서명 | 담당교사`입니다. 복수 담당교사는 쉼표로 구분하며 엑셀은 `담당교사1`, `담당교사2` 두 열도 지원합니다. 금요일 5·6·7교시는 학생 번호와 이름을 대조하여 이 명단에서 담당교사를 찾고 두 교사는 한 셀에 함께 표시합니다. 명단이 없거나 이름이 일치하지 않으면 교사를 추정하지 않습니다. 이어서 나이스 일일 출결 화면을 **캡처해서 Ctrl+V** (제목 줄·머리글 줄이 보이게, 여러 장 가능)
3. 인식 결과 표에서 확인·수정 (칸을 눌러 켜고 끔)
4. 같은 날짜·교시·담당 교사는 **한 행으로 모으고 모든 학생 이름을 함께 적습니다**. 공동 담당교사 중 한 명이 겹치는 경우도 한 행으로 모읍니다. 교사 미확인 행은 각각 남깁니다. 여러 교시는 기본적으로 별도 행이며 옵션을 켜면 같은 학생 목록·과목·교사의 교시를 합칩니다.
5. **새 엑셀 만들기** 또는 **기존 기록 파일에 이어쓰기** (같은 날짜·교시·교사는 기존 행에 학생 이름을 합침), 교사별 요청 문구 복사. 기존 파일에 합쳐진 여러 교시가 있으면 교시별로 나눠 중복을 확인하고, 기존 ‘교사별 요약’ 시트를 갱신합니다.

## 개인정보 보호
- 서버가 없는 정적 사이트입니다. 시간표·캡처·결과는 **브라우저 메모리에서만** 처리되고 업로드·저장되지 않습니다.
- CSP로 사이트 밖으로의 모든 통신을 차단합니다. OCR 엔진(Tesseract.js)과 한글 인식 자료, PDF(pdf.js)·엑셀 라이브러리는 `vendor/`에 함께 들어 있어 외부 CDN을 쓰지 않습니다.
- 쿠키·localStorage·IndexedDB·분석 도구를 쓰지 않습니다.
- 저장소에는 실제 학생 정보를 넣지 마세요. `assets/`, `tests/fixtures/`의 이름은 모두 가상입니다.

## 배포 (GitHub Pages)
`main`에 푸시하면 `.github/workflows/pages.yml`이 공개 파일만 `gh-pages` 브랜치로 올립니다. (Settings → Pages → Source: Deploy from a branch, `gh-pages` / root)
정적 파일이라 학교 내부 웹서버나 내 컴퓨터(`python3 -m http.server`)에서도 그대로 동작합니다.

## 개발
```bash
npm install
npm test          # Playwright로 가상 캡처 → 엑셀까지 끝-끝 테스트
python3 tests/make_fixtures.py   # 가상 시간표/기록 파일 다시 만들기
node tools/make-pdf-fixture.mjs  # 가상 학생별 시간표 PDF 다시 만들기
```
`tools/mock-neis.html`은 예시 캡처와 테스트용 가상 나이스 화면입니다.

현재 테스트 명령은 `tests/weekly.mjs`를 실행합니다. 주차별 조회, 공동 담당교사, 학생 이름 통합, 기존 OCR, 엑셀 생성·이어쓰기, 회전 PDF, 모바일 화면 및 외부 통신이 없음을 검증합니다. `CHROMIUM_PATH`로 Chrome/Chromium 실행 파일을 지정할 수 있습니다. Windows 기본 경로는 설치된 Google Chrome입니다. 이전 `tests/e2e.mjs`는 통합 전 학생별 행 개수를 기준으로 합니다.
